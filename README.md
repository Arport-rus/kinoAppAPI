# kinoAppAPI

Веб-приложение для поиска и просмотра информации о фильмах,
созданное на Vue 3 с использованием API Кинопоиска.

## Возможности
- Поиск фильмов по диапазону годов
- Просмотр карточек фильмов
- Страница с подробной информацией о фильме
- Постеры фильмов
- Асинхронная загрузка данных
- Адаптивный интерфейс
